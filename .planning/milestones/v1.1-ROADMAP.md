## Overview

Removed three demonstrated dead runtime paths and consolidated only the stable list mechanics shared by Logger and Attendance. The milestone preserved controller ownership, visible behavior, localization, persistence, version-5 communication, vendored libraries, and WotLK 3.3.5a compatibility under an explicit accepted-risk disposition.

## Milestone Summary

### Key Decisions

- Delete demonstrated dead paths without deprecation aliases or replacement wrappers.
- Share only stable mechanics; controllers retain all feature and presentation policy.
- Preserve `CalculateColumnWidths` numeric behavior, including its existing `pairs`-derived remainder order.
- Treat a runtime repair after a full gate as invalidating that gate for final acceptance; run one replacement gate on the repaired tree.
- Never convert unavailable live evidence into PASS; close only under the explicitly approved accepted-risk policy.

### Issues Resolved

- Removed three unconsumed runtime exports/forwarders.
- Removed 356 duplicated Logger/Attendance mechanical lines while adding a focused shared surface.
- Reproduced and corrected Screen Notice FontString initialization on WotLK 3.3.5a.
- Repaired stale test fixtures and GSD metadata drift without widening runtime scope.

### Issues Deferred

- Trade live completion plus genuine uncertain-verification retry.
- SavedVariables quarantine/recovery, localized multi-client synchronization, combat lockdown, and taint live checks.
- Dependency optimization: LibDeflate byte compatibility and the talent-library stack decision, reserved for v1.2.

### Technical Debt

- Unused local `GetContentWidth` aliases remain in Logger and Attendance.
- Local test execution still depends on an external LuaJIT `lua.exe`/`lua51.dll` shim.
