# Raid Management Addon

Raid Management Addon is a WoW 3.3.5a raid management addon.

## Commands

- `/rma` - show command help
- `/rma config` - open configuration
- `/rma ml` - open Master Loot
- `/rma history` - open Loot History
- `/rma attendance` - open Raid Attendance
- `/rma res` - open Reserves
- `/rma counter` - open Loot Counter

## SavedVariables

This addon starts clean and uses `RMA_*` SavedVariables.
